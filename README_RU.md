# 🖥️ PicoOS для CC:Tweaked (ComputerCraft)

> Легковесная операционная система с графическим интерфейсом в стиле Windows для мода ComputerCraft / CC:Tweaked в Minecraft. Обладает полной сетевой совместимостью с серверами и протоколами NovaOS.

---

## 🌟 Основные возможности

* **Рабочий стол в стиле Windows** — Синий рабочий стол, интерактивная панель задач, системные часы и полноценное меню «Пуск».
* **Оконный менеджер** — Перетаскивание окон за шапку, изменение размера за правый нижний угол `\`, фокусы и переключение между окнами.
* **PicoOS Pro Shell (Терминал)** — Продвинутая командная строка с поддержкой системных утилит (`ls`, `cat`, `mkdir`, `rm`, `theme`, `ping`, `67`, `reboot` и многих других).
* **NovaMessenger** — Встроенный клиент мессенджера, полностью совместимый с NovaOS. Поддерживает личные чаты, пересылку через сервер и список контактов.
* **Network Config (NetConfig)** — Отдельное приложение для графической настройки и сохранения ID сервера и портов в файл `server_config.txt`.
* **Анимированный экран загрузки** — Фирменный логотип в стиле ASCII-арт и плавная шкала прогресса при запуске системы.

---

## 🚀 Быстрая установка

Чтобы установить PicoOS на любой продвинутый компьютер (Advanced Computer) в Майнкрафте, выполни следующую команду в терминале CraftOS (после загрузки кода на Pastebin):

```bash
pastebin get <твой_код_pastebin> startup

```

*(Или просто скопируй весь код в файл `startup` в корневой директории компьютера).*

## ⌨️ Справочник команд терминала

| Команда | Описание |
| --- | --- |
| `help` | Показывает полный список доступных команд терминала. |
| `ls` | Выводит список файлов и папок с маркерами `[DIR]`. |
| `cat <файл>` | Читает и выводит содержимое текстового файла прямо в окне. |
| `mkdir <папка>` | Создает новую директорию в файловой системе. |
| `rm <путь>` | Удаляет указанный файл или папку. |
| `theme <фон> <шапка>` | Изменяет цветовую тему рабочего стола и окон «на лету». |
| `ping <id>` | Проверяет сетевое соединение с компьютером по его ID. |
| `67` | Выводит на экран большие стилизованные цифры **67**. |
| `killall` | Мгновенно закрывает все открытые окна. |
| `reboot` | Перезагружает операционную систему с экраном загрузки. |
| `exit` | Закрывает текущее окно терминала. |

---

## 🌐 Сетевой протокол (Совместимость с NovaOS)

PicoOS взаимодействует с серверами **NovaOS** через беспроводные модемы:

* Поддержка действия `NEW_MSG` для прямых сообщений серверу.
* Поддержка действия `RELAY_MSG` для пересылки сообщений другим пользователям через сервер.
* Все параметры сети надежно сохраняются в локальном файле `server_config.txt`.
